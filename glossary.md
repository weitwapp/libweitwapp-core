# Glossary
## E
**env**  
environment

## H
**HAL**  
hardware abstraction layer; a concept of making code independet from the underlying hardware

## I
**\<id\>**  
A unique identifier (id) with the format: **YYYYMMDDHHMM**

## R
**REF\<id\>**  
A reference element, e.g. document, note etc.

**REQ\<id\>** or **r\<id\>**   
A requirement

## S
**sry** 
source
